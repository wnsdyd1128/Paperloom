내 PC에서 돌아가는 논문 리더A personal paper reader

읽다가 고른 문장을 바로 묻고
답의 근거는 논문에서 확인하세요 Ask about the sentence you just selected,
and check the answer against the paper

Paperloom은 논문 PDF를 읽는 리더입니다.
읽다가 문장이나 그림, 수식을 고르면 바로 설명이나 번역을 받거나 직접 물어볼 수 있습니다.
AI 기능은 내 PC에 로그인한 Claude Code(claude.ai 구독)로 돌아가므로 API 키가 필요 없습니다.
논문과 기록도 모두 내 PC에 저장됩니다.

Paperloom lets you select a sentence, figure, or equation in a PDF and have it explained, translated, or answered on the spot.
AI features run through the Claude Code you are signed in to on this PC (claude.ai subscription), so you need no API key.
Your papers and notes stay on your machine.

Windows 10/11 64-bit · Claude Code signed in with a claude.ai subscription · no Python or Docker to install

Click a source n tag in an answer to jump straight to that paragraph of the paper.

번역한 쪽은 원문과 같은 레이아웃으로 나옵니다.
원문 문장에 마우스를 올리면 짝이 되는 번역 문장도 강조됩니다.

Pages are translated in their original layout, and each source sentence lights up with its translation.

논문은 내 PC에만Local first

Paperloom 서버는 내 PC 안(127.0.0.1)에서 오는 접속만 받습니다.
논문과 기록도 내 PC에 저장합니다.

The server listens only on 127.0.0.1, and your data stays on this PC.

The Windows zip bundles Python and the models: unzip it and double-click Paperloom.cmd.

주요 기능Features

논문을 등록해 읽고 묻는 일부터 남긴 메모를 나중에 다시 찾는 일까지 Paperloom 안에서 끝납니다.

Everything you need to collect papers, read them, ask about them, and find what you noted later.

서재Library

PDF 여러 개를 한꺼번에 끌어다 놓아 등록합니다(파일당 100 MiB, 300쪽까지). 논문은 제목으로 찾고 태그로 묶습니다.
본문을 다 읽어 들였는지도 목록에 표시됩니다.

Add PDFs by drag and drop (up to 100 MiB and 300 pages each), search titles, tag papers, and check text extraction.

리더Reader

리더는 쪽 미리보기와 목차를 보여 줍니다.
목차가 없는 PDF면 본문 제목으로 목차를 만듭니다.
본문 찾기와 25–500% 확대, 회전도 됩니다.
참고문헌 번호를 Ctrl+클릭하면 참고문헌 목록으로 갔다가 읽던 자리로 돌아옵니다.

Thumbnails and an outline (built from headings when the PDF has none), find in text, 25–500% zoom and rotation, and Ctrl+click on a reference number to jump there and back.

Claude와 대화Chat with Claude

논문 본문 전체나 지금 보는 쪽을 근거로 Claude와 대화합니다.
세 줄 요약도 받고 지난 대화를 다시 열어 이어 묻습니다.
어떤 답에서 갈래를 쳐 다른 방향으로 물어볼 수도 있습니다.
모델은 Sonnet, Opus, Haiku 가운데 고릅니다.

Chat grounded in the paper text or the current page, three-line summaries, saved conversations with branches, and a choice of Sonnet, Opus, or Haiku.

쪽 번역Page translation

번역은 원문 레이아웃 그대로 보거나 글만 모아 읽거나 별도 탭에 띄웁니다.
논문 전체를 한 번에 번역할 수도 있습니다.
수식과 표, 그림 속 글자, 참고문헌은 원문으로 두고 그림과 표의 캡션은 번역합니다.

Keep-layout, reading, and separate-tab views, plus translate all pages.
Equations, tables, text inside figures, and references stay as they are; captions are translated.

그림·표·수식Figures, tables, equations

그림이나 표, 수식을 영역으로 잡아 설명을 받거나 이미지로 복사합니다.
수식은 LaTeX와 기호 설명으로 받습니다.

Pick a region to have it explained (equations as LaTeX with symbols described) or copy it as an image.

기록Notes and history

패널에서 하이라이트와 주석을 검색하고 색과 종류로 거릅니다.
Markdown으로 한 번에 복사할 수도 있습니다.
모든 논문의 대화는 답변 화면 한곳에 모입니다.

Highlight and note panels (search, filter by colour or kind, copy all as Markdown) and an answers view that gathers conversations from every paper.

PDF로 내보내기PDF export

하이라이트, 주석, 설명, AI 질문 가운데 고른 것을 원문 PDF에 넣어 내려받습니다.
하이라이트는 원문 위에 같은 색으로 칠하고, 주석과 설명, AI 질문은 쪽 여백에 PDF 메모로 붙입니다.
설명과 AI 질문 메모에는 Claude의 답도 들어갑니다.

Download the original PDF with the highlights, notes, explanations, and AI questions you choose, added as standard PDF annotations.
Highlights keep their colour; the rest become margin notes that include Claude's answers.

설정Settings

답변과 번역 언어(한국어, English), 기본 모델, Claude에 보낼 본문 길이, 다크 모드, 글꼴 크기를 바꿀 수 있습니다.
설명·번역·요약을 부탁할 때 쓰는 문장(프롬프트)도 원하는 대로 고칩니다.

Answer and translation language (Korean or English), default model, paper text limit, dark mode, font size, and personalised prompts.

동작 방식How it works

Paperloom은 내 PC에서 서버와 Claude Code 브리지, 두 프로그램으로 돌아갑니다.
브라우저 화면은 논문과 기록을 서버에서 가져옵니다.
AI 기능을 쓸 때는 브리지에 요청을 보냅니다.
PC 밖으로 나가는 데이터는 Claude Code가 Anthropic에 보내는 질문과 근거 글뿐입니다.

Paperloom runs as two programs on this PC: a server and the Claude Code bridge.
The browser loads papers and notes from the server and sends requests to the bridge only when you use AI features.
The only thing that leaves your PC is what Claude Code sends to Anthropic: your question and its sources.

내 PC에서 돌아가는 프로그램Runs on this PC 외부 서비스External service
  • 서버는 PDF를 보관합니다.
    글자 층이 있는 PDF는 본문을 뽑아 검색과 근거, 번역에 씁니다.
    표나 알고리즘, 수식, 그림, 머리글은 문서 레이아웃 모델(PP-DocLayout_plus-L)로 찾아 번역에서 뺍니다.
    글꼴 정보만으로 읽지 못한 글줄은 글줄 인식(OCR) 모델(PP-OCRv6_small_rec)로 읽어 채웁니다.
    두 모델 모두 내 PC에서 돌아갑니다.
  • The server stores your PDFs and extracts the text of those with a text layer for search, sources, and translation.
    A layout model (PP-DocLayout_plus-L) finds tables, algorithms, equations, figures, and headers to keep out of translation, and a text-line model (PP-OCRv6_small_rec) fills in lines the font data cannot read.
    Both models run on this PC.
  • 브리지는 내 PC에서 claude CLI를 실행해 Claude에게 질문을 넘깁니다.
    브리지를 꺼도 논문 읽기와 검색, 하이라이트, 주석은 그대로 쓸 수 있습니다.
  • The bridge runs the claude CLI on this PC.
    Reading, search, highlights, and notes keep working while it is off.

시작하기Get started

Windows에서는 Claude Code만 준비하면 됩니다.
Paperloom에 필요한 Python과 라이브러리, 모델은 압축 파일에 다 들어 있습니다.

On Windows all you need is Claude Code.
The zip includes the Python runtime, libraries, and models Paperloom uses.

  1. Claude Code 설치·로그인Install Claude Code and sign in

    아래 명령으로 PowerShell에서 Claude Code를 설치합니다(설치 안내). 새 터미널을 열어 claude를 실행하고 claude.ai 구독 계정으로 로그인하세요.
    API 키로 로그인한 Claude Code는 브리지가 받지 않습니다.

    Install Claude Code from PowerShell (setup guide), then run claude in a new terminal and sign in with your claude.ai subscription.
    The bridge refuses API-key sign-ins. 

    irm https://claude.ai/install.ps1 | iex

  2. Paperloom 받기Download Paperloom

    Paperloom-windows-x64.zip을 받아 압축을 풉니다.
    경로가 길면 압축을 풀 때 오류가 날 수 있으니 C:\Paperloom처럼 짧은 경로에 푸세요.

    Get Paperloom-windows-x64.zip and unzip it to a short path such as C:\Paperloom.

  3. 실행Run it

    Paperloom.cmd를 두 번 누르면 서버와 브리지가 켜지고 브라우저에 http://127.0.0.1:8000이 열립니다.
    서명하지 않은 파일이라 처음 실행하면 Windows 경고 창이 뜰 수 있습니다.
    경고 창에서 추가 정보 → 실행을 누르세요.
    등록한 논문과 기록은 %USERPROFILE%\.paperloom\data에 저장됩니다.

    Double-click Paperloom.cmd: the server and the bridge start together and your browser opens http://127.0.0.1:8000.
    If Windows shows a warning the first time, choose More info → Run anyway (the file is unsigned).
    Your library lives in %USERPROFILE%\.paperloom\data.

리눅스나 macOS, NVIDIA GPU에서 쓰려면Linux, macOS, or an NVIDIA GPU

서버는 Docker로 띄우고 브리지는 따로 켭니다.
아래 시작 스크립트는 NVIDIA GPU가 있으면 GPU 이미지를 고릅니다.
자세한 방법은 README의 Docker로 실행을 보세요.

Run the server with Docker and start the bridge separately; with an NVIDIA GPU the start script picks the GPU image.
See Run with Docker in the README (Korean). 

git clone https://github.com/wnsdyd1128/Paperloom.git
cd Paperloom
powershell -ExecutionPolicy Bypass -File ops\start.ps1

데이터와 개인정보Data and privacy

논문과 기록은 내 PC에 저장됩니다.
어떤 데이터가 어디에 남고 무엇이 밖으로 나가는지 아래에 적었습니다.

Your papers and notes stay on this PC.
Here is what goes where.

  • 저장 위치는 Windows 압축 파일로 실행하면 %USERPROFILE%\.paperloom\data, Docker로 실행하면 볼륨 paperloom_paperloom-data입니다.
  • Where it is stored: %USERPROFILE%\.paperloom\data for the Windows zip, the paperloom_paperloom-data volume for Docker.
  • 접속은 내 PC에서만 됩니다.
    서버와 브리지가 127.0.0.1로만 열려 있기 때문입니다.
  • Who can connect: the server and the bridge listen only on 127.0.0.1, so only this PC can reach them.
  • Anthropic에 보내는 것은 질문과 질문의 근거로 붙이는 글(고른 글과 앞뒤 문단, 고른 대화 범위 안의 논문 본문, 고른 영역 이미지), 번역할 쪽의 문단입니다.
    사용량은 claude.ai 구독에서 빠지며 Anthropic 말고 다른 외부 서비스는 부르지 않습니다.
  • What goes to Anthropic: your question and its sources (the selection and nearby paragraphs, paper text within the chosen scope, selected region images) and the paragraphs of pages you translate.
    It counts against your claude.ai subscription; no other external service is called.
  • Paperloom은 API 키를 쓰지 않습니다.
    환경 변수에 API 키가 있어도 브리지는 Claude Code에 넘기지 않습니다.
  • API keys: none are used.
    Even if one is set in your environment, the bridge does not pass it to Claude Code.
