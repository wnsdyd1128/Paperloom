# 논문 쉽게 풀어 정리 (distill-paper)

받은 논문 본문(Paperloom 근거)을 읽고, 핵심을 쉬운 말로 다시 짠 아티팩트 하나를 만든다.

인자: $ARGUMENTS
(독자 수준이나 강조할 점이다. 비어 있으면 그 분야를 막 배우기 시작한 대학원생을 독자로 본다.)

## 먼저 확인할 것

- 이 대화에서 쪽마다 ¶번호가 붙은 논문 본문 근거를 받지 못했으면 아티팩트를 만들지 않는다. 대화창의 범위를 "논문 본문"으로 두고 다시 불러 달라고 한다.
- 근거 끝 "범위와 출처"에 빠진 쪽이 있으면, 그 부분은 다루지 못했다고 아티팩트와 설명 글 모두에 적는다.

## 뽑을 것

근거에 있는 것만 뽑는다.

1. 한 줄 요지
2. 문제와 동기: 무엇이 안 되고 있었고 왜 중요한지
3. 핵심 아이디어: 기존 방법과 무엇이 다른지
4. 방법: 입력에서 출력까지의 흐름(3–7단계)
5. 실험 설정과 결과: 데이터·비교 대상·지표와 주요 수치
6. 한계와 열린 질문: 저자가 밝힌 것과 읽으며 본 것을 나눠 쓴다
7. 꼭 알아야 할 용어 5–10개

- 수치·데이터셋 이름·비교 대상은 근거 글에 있는 그대로 옮긴다. 근거에 없는 수치는 만들지 않는다.
- 쉽게 바꿔 말한 비유나 배경 설명은 근거 밖 내용이다. 아티팩트에서는 "쉽게 말하면"처럼 표시해 논문 내용과 구분한다.

## 아티팩트

- 형식: ```artifact type="html" title="<논문 짧은 제목> 한눈에 보기"
- 위 일곱 가지를 차례대로 절로 둔다. 맨 위에 한 줄 요지와 목차를 둔다.
- 방법 흐름은 인라인 SVG나 CSS 상자로 그린다(바깥 라이브러리 없음).
- 결과는 HTML 표로 보인다. 비교가 핵심이면 인라인 SVG 막대를 더하고, 막대 길이는 표의 수치로만 정한다.
- 원본 그림이 설명을 돕는다면 "이 논문의 그림" 목록의 번호로 넣는다(`<img src="paperloom-figure:3" alt="Figure 3">`). 그림마다 무엇을 보면 되는지 한 줄 붙인다.
- 각 절 끝에 그 절이 기댄 근거를 작게 적는다(예: 근거 3¶2, 5¶1). 아티팩트 안의 근거 표기는 눌러 원문으로 갈 수 없으니, 핵심 근거는 아티팩트 밖 설명 글에도 [근거 n¶m]으로 적는다.
- 크기: 답 전체(아티팩트 포함)를 35,000자 안으로 쓴다. 넘칠 것 같으면 용어와 한계 절부터 줄인다. Paperloom은 50,000자가 넘는 답을 저장하지 못한다.

## 답의 차례

1. 아티팩트 앞: 무엇을 만들었는지 두세 문장
2. 아티팩트
3. 아티팩트 뒤: 논문의 핵심 주장 세 가지를 [근거 n¶m]과 함께 목록으로 쓰고, 다루지 못한 부분을 적는다
